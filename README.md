# Pantry Remix

Pantry Remix is an AI-powered web app that turns ingredients a user already has into one practical recipe with clear, timed cooking steps. It is an MVP for the CS4680 AI Assistant Project.

## Problem

People often have usable ingredients at home but cannot quickly decide what to cook with them. Searching traditional recipe sites creates extra work because recipes may require missing ingredients, bury instructions in long pages, or assume more experience than the user has.

Pantry Remix collects ingredients, optional dietary restrictions, cooking time, servings, and skill level, then generates a recipe that prioritizes those constraints. The result includes ingredients already available, a short list of pantry basics, timed instructions, substitution guidance, a food-safety note, and a step-by-step cook mode.

## AI and prompt engineering

The server route in `app/api/recipe/route.ts` calls the OpenAI Responses API and uses Structured Outputs so every result follows one JSON schema.

Three course prompt-engineering patterns are visible in the implementation:

1. **Persona pattern:** The model acts as a practical home chef and food-waste reduction mentor teaching a home cook. This keeps the writing clear and the recipes realistic.
2. **Few-shot pattern:** The prompt contrasts a good pantry-first response with a bad response that adds specialty ingredients, gives vague steps, or invents user inputs.
3. **Iterative refinement:** After receiving a recipe, the user can request a faster version, fewer extras, or more protein. The previous structured recipe is sent back with the refinement so the model preserves the core dish while applying the change.

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Add `OPENAI_API_KEY` to `.env.local` for live AI generation. The app requires the key because the recipe title and every cooking step are generated by the AI from the user's current ingredients.

Optional model override:

```text
OPENAI_MODEL=gpt-5.6-terra
```

Never commit `.env.local` or an API key.

## Demo flow

1. Explain the problem in one sentence: ingredients are available, but deciding what to cook is difficult.
2. Enter four ingredients or choose a sample pantry.
3. Optionally check dietary restrictions, then select time, servings, and skill level.
4. Generate the recipe and point out the pantry-first ingredient list and timed steps.
5. Use **Make it faster** to demonstrate iterative refinement.
6. Open **Cook mode** to show the step-by-step cooking experience.

## Architecture

```text
Browser form
   ↓ JSON request
POST /api/recipe
   ↓ engineered prompt + JSON schema
OpenAI Responses API
   ↓ validated structured recipe
Responsive result view + cook mode
```

## Safety and privacy

- The OpenAI API key stays on the server.
- Inputs are length-limited and treated as data rather than instructions.
- Generated recipes include an allergy and food-safety reminder.
- The Responses request uses `store: false`.

## Technology

- React 19 and TypeScript
